# Concept-based investigation and Bob's native control

Start with the mathematical question, then select controls. Example: “How does changing rows while columns stay fixed change the product?” on F3-01 means actual editable rows/columns, relevant bounds, an invariant fixed column count for one experiment, and an optional comparison where both vary. It is not a quiz and not a menu of factor-tree/rotation/split modes unrelated to that inquiry. Keep enough values and cases for genuine exploration.

For each concept record objective; investigation; allowed changes; invariant; expected observation; starting/reset native model; exact accessible controls; hidden irrelevant modes; keyboard/pointer method; at least two contrasts; independent instance behavior. Use actual `P.exploreBindings[conceptIndex]` and native variable/control policy, with family-specific documented fields. Hide irrelevant presets; do not hide essential manipulation or label an unchangeable picture “Explore”. Verify real input, not just field presence. Restore defaults must restore this concept's configured model and policy, not stock examples.

F1 uses actual native `data`/`scene` and separate record motion when supported. F2 uses documented `data.lesson` and whitelisted native actions. F3 uses full `data.lesson.state`, supported `phase` or `motion:{from,to,durationMs}`. These are families, not one universal shape. Read source-reference guides and actual source, including initial defaults that may conceal labels/working. Set the full relevant state explicitly.

Bob uses independent programmatically driven native records: set all givens, establish units/whole, predict/pause, transform/reveal, explain the invariant and connect written mathematics. He can use native hooks/constructors to control the required drawing states and motion; no pupil action is a precondition. Add a narrowly exposed native method if needed, preserve source drawing code/style, and test it. Record state/action/phase inputs and completion/cancel signals rather than promise abstract “full control”.

For Watch and Guided, specify actual start→intermediate→end maths and caption/speech cues. Reuse original player/TTS/clock. Voice completion and native completion form a barrier. Reading fallback is explicit; controls cancel old work and start the correct selected state. Later answers stay concealed in both visual and written output. Direct step selection and Reset must produce the same valid state as sequential playback. Reduced motion uses valid static/final evidence, not skipped maths.

Compare independent representations with the existing native views/independent instances where useful. Each source keeps state and reset. Changes in one pupil Explore cannot change Bob, another concept or another native frame. Test mixed F1/F2/F3 lesson bindings and the actual reset path, not only a source opened alone.
