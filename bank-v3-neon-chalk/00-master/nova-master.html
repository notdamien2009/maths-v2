The working document for the KS3 maths build. Lessons are renumbered with no gaps, assessments sit after the lessons they follow, and every lesson is mapped to the visual engine components it needs. Six assessments per year: five topic tests (18 questions, or 20 where a new lesson was added) plus one 36-question cumulative test.

Production lock: one lesson = one mathematical concept. The five Bob Learn panels must be five stages, representations, examples or applications of that same concept. They must never be five separate curriculum objectives.
Drawing Style Lock · Neon Tube + Chalk (house style v3, locked)

Rule: never apply bbox glow filters to straight lines. All glow filters (nv-neon, nv-neon-soft, nv-neon-halo, nv-glow, nv-shadow, nv-chalk, sl-*) use filterUnits="userSpaceOnUse"; a percentage filter region on a perfectly horizontal or vertical line has zero height, so the line disappears.

PLACE COLOURS (v3.6): place-value engines colour columns by PLACE, using the separate core token set NOVA.place / NOVA.placeColour(p) / CSS --pv-th --pv-h --pv-t --pv-o --pv-t1 --pv-h1 --pv-th1 (Thousands #a78bfa purple, Hundreds #818cf8 indigo, Tens #60a5fa blue, Ones #2dd4bf teal, Tenths #c084fc violet, Hundredths #f472b6 pink, Thousandths #fb923c orange) plus NOVA.placeKey(). Place colours mean WHICH COLUMN only, never a maths role; gold (focus/placeholder) and green (result) keep their maths-role meaning on top. Owner pick: PV chart Option A (place cards, worth line, gold highlight, dotted decimal divider, key). Motion in place-value engines uses core NOVA.motion (tween/spring/back easing, trail, flash, pop; instant under reduced motion) and drags use NOVA.ui.svgDrag with spring-back; every drag has a keyboard alternative.

LOCKED NUMBER LINE (v3.5): every number line, scale line, power/log line, zoom line and error-interval line is drawn ONLY with core NOVA.numberLine(opts) (or NOVA.svg.axes({numberLine:true}), which calls it). Look: the approved F0-03 line: a neon glass tube with arrowheads at both ends, a straight, evenly sized neon line at every major value, minor values only as shorter straight lines in the same style (never dots or beads), chalk-draw digits centred under the lines. Vertical lines use vertical:true. Engines must not draw their own ticks; build.py fails on custom tick loops (mark real exceptions such as a round dial or a grid with /*nl-ok*/).

Rule for every prompt: all maths drawings are Neon Tube, all writing, numerals and labels are Chalk. Draw ONLY through the core primitives in core/nova-core.js (v3.x) with core/nova-core.css. Do not invent new drawing styles, filters, line weights or fonts. Reference build: F0-02 SVG primitives (owner-approved). Source of truth: NOVA.houseStyle={drawing:'neon',writing:'chalk',locked:true}.

Stroke widths and layering

  • Neon tube (inkLine, hop, brace, arc, curves) = 4 layers, bottom to top: soft halo (width w+10, opacity .16, #nv-neon-soft) → mid halo (w+4.5, opacity .5, #nv-neon-halo) → coloured tube (w, #nv-neon) → white core (max(1, w×0.35), opacity .92). Via NOVA.premium.halo().
  • Widths: inkLine 2.8 · arrow / hop 3.5 · brace / arc 3 · right-angle mark 2.5 · axes 2.2 · number line 2.8 · ticks 2 (minor 1.2) · grid 1 at opacity .14 (#44baff).
  • Caps and joins are always round. Ends of ink lines get glass end-caps: a glow dot (r+1.4, opacity .3, soft filter) under a #e0f7ff dot with a role stroke, r = w×0.55+1.4.
  • Points / cues: role shape (given square, unknown dashed circle, op diamond, result tick, error cross, focus star, support triangle) on a bead glow (r+5 at .22 soft, r+2 at .45 halo). Default r = 7.
  • Arrows: marker #nv-arr-<role>, path M1,1.5 L10,6 L1,10.5 Q3,6 1,1.5z, markerWidth 5 (ink 4), orient auto-start-reverse.
  • Arcs: role default focus (orange), filled wedge with #nv-fill-<role> (stop .34 → .06), exactly 90° draws a square right-angle mark, ≥ 359.5° draws as two half-arcs (a full circle, never blank).
  • Braces: role default given (blue), depth 10, label pill offset depth×1.4+16 from the brace.
  • Labels: NOVA.svg.label() and NOVA.svg.pill() only. Pill = rounded capsule (rx = h/2) with role border, chalk lettering weight 800, dark outline paint-order:stroke;stroke:#030819;stroke-width:.7px.

Do / Don't

  • DO use role colour + role shape for every meaningful mark (colour-blind safe).
  • DO keep the dark stage (--v-bg) so the neon reads; keep chalk light and readable (displacement scale stays 1.6).
  • DO match F0-02 for look, spacing and label sizes.
  • DON'T add new filters, gradients, drop-shadow styles, line weights, dash patterns or fonts.
  • DON'T draw flat 1px lines, square caps, plain system text on the stage, emoji or clip-art as maths.
  • DON'T use cartoon/3D/photo-real/paper/sketch styles for maths objects; real-world props (dice, clocks, protractor, solids) are drawn as neon tube outlines with chalk labels.
  • DON'T let anything overlap the maths: labels, pills, the helper, bubbles and controls must sit clear of drawn maths. Use pointTo; if no clear spot exists the helper stays home.
  • DON'T put a box, panel or background behind the helper: transparent pose PNG only, bottom-right, feet on the baseline.

Per-family notes (from user-picks.json, 101 picks: chalk 57 · neon 43 · blueprint 1)

  • House decision overrides per-row picks: Neon drawings + Chalk writing everywhere.
  • Blueprint is allowed only for the reusable table engine (pick SYS-07 → F0-15 Interactive table): blueprint grid behind the table cells, still with neon highlights and chalk entries. Nowhere else.
  • Chalk-heavy families (Factors, Fractions, FDP, Ratio, Finance, Algebra, Sequences, Statistics, Probability, System text): writing carries the lesson, so keep drawings minimal neon accents.
  • Neon-heavy families (Number lines, Graphs, Geometry, Measurement, Rates): neon tube for lines, axes, shapes and arcs; chalk only for labels and values.
  • Topic layer data-topic changes accents and motifs only, never layout or drawing style.

v3.2 lock: two chalk fonts + house helpers (core v3.0+house3.2)

  • Built-in font: "NOVA Chalk" (free Kalam font, embedded in core/nova-core.css, so it looks the same on any PC). Never use Inter, serif, Cambria or mono for on-stage maths. UI buttons/tabs may stay Inter.
  • --nova-font-chalk-draw: every label INSIDE a drawing (number-line digits, 50°, A/B/C, +3 pills, brace labels). Always rendered with the scratchy filter:url(#nv-chalk) texture, exactly as F0-02. Used automatically by NOVA.svg.label, NOVA.svg.pill and NOVA.chalkText.
  • --nova-font-chalk-write: written maths away from drawings (equations, working, questions, answers, token demos). Smooth bold chalk with neon glow (--nv-chalk-glow). Applied by default to .mt, .nova-maths, .nm, .nv-num and stage inputs.
  • Drawings: premium Neon Tube only (halo + soft glow + coloured tube + white core, glass end caps). No dark rectangle frame behind diagrams.
  • Focus/result marker: neon ring with pulse (NOVA.neonRing). The old star marker is retired; the focus role shape is now "ring".
  • Helpers (use these, never plain shapes/text): NOVA.chalkText(svg,x,y,text,o) · NOVA.neonLine · NOVA.neonPath(svg,d,{role,width,fill,dash}) · NOVA.neonBox(svg,x,y,w,h,{role,text}) · NOVA.neonRing(svg,x,y,{role,r,pulse}) · NOVA.neonMark(svg,x,y,ok) · NOVA.neonPlot(svg,o) · HTML: NOVA.neonTile(text,{role}) · NOVA.neonCard(children,{role}) · NOVA.answerChip(text,ok). The hop, arrow, axes, grid and plot.marker primitives are neon by default.
  • Fractions: LOCKED — use traditional stacked fractions: NOVA Chalk numerator above a full horizontal fraction bar above the NOVA Chalk denominator. Use NOVA.mt.render for HTML maths, or NOVA.chalkText plus NOVA.neonLine for SVG mathematical evidence. Inline n/d is permitted only in compact controls. Do not use fraction-TBD placeholders. The owner decision is recorded in F5/F5-FRACTION-NOTATION-LOCK.md.

F0 status: ALL 17 COMPLETED & APPROVED (v3.x) · Lessons learned

  1. Build F1 onward only from approved F0 engines + core helpers (neonLine, neonPath, neonBox, neonRing, neonMark, neonPlot, neonTile, neonCard, answerChip, chalkText). Missing something? Add it to core first.
  2. Two chalk fonts: draw (labels in drawings, scratchy) and write (written maths, smooth glow). Both embedded.
  3. Number lines: a straight line at every digit. Markers: neon ring, never a star. No frame behind diagrams, no box behind the helper.
  4. No role glyphs on maths text or values; colour only (glyphs only in colour-key legends).
  5. Hide developer / LaTeX / markup code from pupils behind "Developer: show code".
  6. Powers small and raised top-right, like handwriting.
  7. Every pupil-facing screen fully premium (controls, inputs, feedback, ticks/crosses), no empty stage space, nothing overlapping maths.
  8. Fractions: traditional stacked NOVA Chalk numerator/bar/denominator notation (owner-locked). No neutral placeholders.
  9. Print fallback: clean black-and-white and legible.
  10. Glow filters: Never apply bounding-box (objectBoundingBox / percentage) glow filters to straight lines, axes, ticks or grid: every glow filter uses filterUnits=userSpaceOnUse (build.py fails otherwise).
