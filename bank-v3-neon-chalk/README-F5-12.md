# NOVA F5-12 — Premium Percentage Grid

Interactive hundred-square percentage engine: 100 equal squares, paint/erase, precise percentage and decimal output, stacked NOVA Chalk fraction notation, core motion and drag, Watch / Guided / Explore / Challenge.

- **Open:** `F5/F5-12-hundred-square-percentage-grid.html`.
- **Editable source:** `build/F5-12.src.html`.
- **Build:** run `python build/build.py` from the top folder (requires sibling F0/F5 sources included here).
- **Browser QA:** `python tests/qa_f512.py` and `python tests/stress_f512.py`, using Playwright + local Chromium.
- **Evidence:** `tests/f512-results.json`, `tests/f512-stress.json`, screenshots under `shots/F5/`.
- **Do not replace:** other F5 components or original F0/F1 production sources until owner approval.
