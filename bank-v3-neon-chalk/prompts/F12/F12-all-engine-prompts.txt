
#### F12-01 Shape family tree
Build NOVA Master Visual Engine component F12-01: "Shape family tree" (Family F12: 2D Shapes, Perimeter and Area).
Family covers: shape properties, perimeter, area, circles.
Used in these KS3 lessons:
- Y7-045 Properties of 2-D shapes (objective: Classify triangles, quadrilaterals and polygons by properties.)
- Y7-057 Introduction to congruence (objective: Recognise congruent shapes as identical in size and shape.)

First give a short spec card: maths purpose, year groups, parameters, presets (cover the range the lessons above need), animation steps, interactions and what counts as correct, misconception traps it exposes, GCSE extension flag, linked components. Then build it.

Standards: ONE self-contained HTML file (inline CSS/JS/SVG, no external libraries), mobile-first at 380px wide, NOVA design tokens and the locked NOVA maths colour language, colour-blind safe (shape or pattern as a second cue). Expose a config object at the top with parameters and named presets. Provide four modes: Watch (auto animation), Guided (stepped with prompts), Explore (free manipulation), Challenge (task with checking). Animation is a named step sequence with play, pause, step back/forward, scrub and reset, plus a narration slot per step for the Sir Bob tutor. Emit events (value, correct, step, hint used). Keyboard operable, respects reduced motion, alt text, static fallback for print. Contain NO game logic: games are run by the F0-12 game wrapper. Build the component to be reusable across lessons, not tied to one lesson. Drawing style: use the Drawing Style Lock in the master document (Neon Tube for all maths drawings, Chalk for all writing, labels and numerals) and the core primitives in core/nova-core.js v3.x with core/nova-core.css; F0-02 is the visual reference. Do not invent new drawing styles, filters, line weights or fonts. Draw only through the core primitive functions (NOVA.svg.root, inkLine, arrow, hop, brace, arc, grid, axes, cue, label, pill) and the v3.2 house helpers (NOVA.chalkText, neonPath, neonBox, neonRing, neonMark, neonPlot, neonTile, neonCard, answerChip). Labels inside drawings use --nova-font-chalk-draw with the chalk texture; written maths uses --nova-font-chalk-write with neon glow. Nothing may overlap the maths, and the helper has no box or background behind it. F0 FOUNDATION LOCK (mandatory for F1 onward): F0-01 to F0-17 are COMPLETED and APPROVED (v3.x). Build ONLY from the approved F0 engines and the core helpers in core/nova-core.js + core/nova-core.css: NOVA.neonLine, neonPath, neonBox, neonRing, neonMark, neonPlot, neonTile, neonCard, answerChip, chalkText (plus NOVA.svg axes/hop/arc, NOVA.mt, NOVA.ui controls, NOVA.assess, game wrapper F0-12, worked example F0-13). Reuse F0 patterns (stage caption, helper strip, side neon cards, four modes). Rules: every drawing is Neon Tube; number lines draw a straight line at every digit; labels inside drawings use --nova-font-chalk-draw, written maths away from drawings uses --nova-font-chalk-write (two chalk fonts, both embedded); result/position markers are a neon ring, never a star; no dark frame or box behind diagrams; no box behind the helper; no role glyphs (★ ■ ◆ ✓ ◌ ▲) attached to maths text or values (colour only; glyphs only in explicit colour-key legends); no overlaps with maths; no empty stage areas; fractions stay a neutral placeholder tagged 'approved NOVA Chalk stacked fraction notation' until the fraction design is decided. F0 LESSONS LEARNED: hide developer/LaTeX/markup code from pupils (behind a collapsed 'Developer: show code' toggle); powers and exponents are small and raised top-right of the base like handwriting; every pupil-facing screen (all 4 modes, 380px and desktop) must be fully premium neon + chalk, including controls, inputs, feedback and ticks/crosses; no Inter/serif on stage maths (UI buttons/tabs may stay Inter); print fallback stays clean black-and-white.
