# Generated Studio Specification Data

Source: `00-master/nova-master.html` (embedded `/*SPEC*/var SPEC={...}` object). To regenerate: `python prompts/specs/gen.py`. To compare: `python prompts/specs/gen.py --check`.

Older master instructions referred to historical editorial input scripts `s1-s6.py`, which are not in the audited repository. This utility recovers **exactly the embedded data that exists now**. It makes no claim to restore or reconstruct the missing human editorial history. `specs.json` is derived output; the canonical HTML master is authoritative.
