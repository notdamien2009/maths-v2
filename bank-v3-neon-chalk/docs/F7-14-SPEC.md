# NOVA F7-14 · Identity Visualiser — short spec card

**Purpose:** Demonstrate whether two algebraic expressions are identical for *every* possible x by comparing signed coefficients of x², x and 1. A true identity is not the same as one coincidentally equal value.

**Year groups:** Year 9 and GCSE bridge. Lesson Y9-006 Algebraic equivalence.

**Parameters:** Two signed degree-two polynomial vectors (x²/x/constant, max eight of each tile type), independently displayed symbolic expressions, selectable lesson presets and a sample x value for disproving non-identities. Maximum eighteen on-stage movable tiles for a single pair.

**Presets (6):** Y9-006 distributive identity; quadratic expansion identity; difference of two squares; false square of a sum; equality only at x=0; signed coefficient collection.

**Watch / Guided named stages (6):** Notice both expressions → reveal algebra tiles → build left expression → build right expression → compare each signed coefficient → prove/disprove identity. Tutor narration slot on every stage; Sir Bob remains the tutor, Pip/Nova act as helper mascots.

**Explore:** Pupils can drag positive/negative tiles from the tray to their original left/right mats, undo, return or reset, choose a named preset, request a hint or automatically build the exact representations. The visual proof reveals only after Compare.

**Challenge:** Four rounds, two true identities and two false identities. Build the two sides before choosing Identity/Not identity. Corrections explain missing cross-terms, unequal unit coefficients and why matching one test value is insufficient. No answers are revealed before submission.

**Correct:** Signed coefficient vectors agree across x², x and the constant term. A numerical counterexample at x=2 illustrates non-identities; a single numerical test never proves identity.

**Interactions:** NOVA.ui.svgDrag zones for left/right mats, red Return, keyboard Enter/L/R/Delete, undo, Escape/pointer cancellation, reduced motion. Incorrect-side drops spring back to their original positions with specific feedback.

**Misconception traps:** Mixing powers, dropping negative signs, missing middle terms in (x+1)², treating x=0 agreement as a universal identity, putting tiles on the wrong mat.

**GCSE flag:** Yes, equivalence, expansion and polynomial identities. No game code (F0-12 wrapper handles games).

**Linked:** F7-01 Algebra Tiles, F7-03 Collecting Like Terms, F7-05 Expanding Double Brackets (F3-02 preset), F7-13 Difference of Two Squares.

**Rendering:** F0 approved v3.x NOVA Neon Tube and Chalk drawing helpers only. No custom SVG filters, fonts or core modifications; mobile 320/380 and desktop 768/1280 verified. Positive/negative distinguished by both neon role and striped negative patterns.
