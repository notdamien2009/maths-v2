# F8-03 — Function Machine · NOVA Maths

Source of truth: `00-master/NOVA-MASTER-FOR-OTHER-AI.md` → F8-03 prompt (GitHub `notdamien2009/maths-v2/main`).

**Purpose:** Turn algebraic notation into a two-step operation machine; show an input hopper, two working gear wells, and an output chute with a table of corresponding values.

## Lesson presets

| ID | Objective | Rule and input/output model |
|---|---|---|
| Y7-028 | Algebraic notation | y = 3x + 2; multiplication precedes addition |
| Y7-030 | Substitution into a formula | y = 2x + 5; handles negative input |
| Y7-033 | Two-step equations and inverse operations | 2x + 3 = 15; forward 2x then +3; reverse −3 then ÷2 |
| Y8-016 | Rearrange formulae | y = 5x − 4; forward ×5 then −4; reverse +4 then ÷5 |

Named teaching steps: input card; first operation; second operation and output; complete x/y value table.

**Watch/Guided:** Show only the currently justified step and the correct method. Bob narration is individual to the lesson and stage.

**Explore:** Drag input cards to hopper, and operation cards to either gear well. The output and table calculate from the user's selected rules. Re-grab to remove; keyboard Enter/Delete alternatives; reset and selection controls.

**Challenge:** Four tasks, one per lesson. Must select the two operations in the correct order AND calculate the final value. Exact value kept hidden until marked. Misconception-specific feedback on wrong rule or numeric result.

**Shared preset architecture:** F7-12, F8-02, F8-04 are defined by the master as presets of this engine. Their distinct visual presentations/entry files are reserved for their planned later review runs, not claimed here as built.

**Style:** F0 Neon Tube + NOVA Chalk. F0 drawing helpers only. Core embedded for preview; separate current-core rebuild script. Poses from the existing inline NOVA mascot runtime.

**Acceptance:** 380/1280 all four modes; 430/760/1024 additional layouts; pointer pickup, drag/drop, return, invalid drop and keyboard interaction; maths check; user review and approval.
