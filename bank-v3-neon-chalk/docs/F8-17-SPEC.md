# F8-17 Spec card — Algebraic Proof Builder

| Field | Production specification |
|---|---|
| Mathematical purpose | Construct a general algebraic argument through four statements and three justified implication links; separate an example from a proof. |
| Year groups | Year 9 extension and GCSE. **No KS3 lesson mapping is assigned in current master.** |
| Parameters | Proof key; integer variables and valid integer identities; seven positions; ordered statement/justification cards; incorrect distractors; stage and mode. |
| Presets | ODD-SUM, THREE-CONSEC, EVEN-SQUARE, ODD-SQUARE, MULTIPLE-FIVE, SQUARE-DIFF. |
| Animation | State claim → premise → first reason → transformed expressions → conclusion; F0 `NOVA.motion.arrive` and reduced-motion fallback. |
| Interactions | Drag selected statement/reason from SVG chip to an appropriate link; click/keyboard bank+slot alternative; wrong-link reject, re-grab return zone, undo, reset, hint. |
| Marking | Exact proof validity is checked for all seven positions and their link types. Each supplied mathematical chain is independently checked on integer examples; the underlying proof remains the symbolic reasoning represented on the board. |
| Misconceptions | Examples cannot prove universality; cancellation/expansion mistakes; missing middle terms; incorrect parity; non-sequiturs; counting three integers incorrectly. |
| GCSE extension | Integer algebraic proof, parity and divisibility. |
| Dependencies | F0-02, F0-04, F0-05, F0-07, F0-08, F8-07, F8-08, F8-15. Uses current F0 Neon Tube+Chalk helpers, mascot dock and bank wrapper. |
| Approval status | Premium review candidate only. Rebuild on current F0 core; owner sign-off remains necessary. |
