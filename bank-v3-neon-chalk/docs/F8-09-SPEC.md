# F8-09 — Substitution Table · Production specification

**Master source:** `bank-v3-neon-chalk/00-master/NOVA-MASTER-FOR-OTHER-AI.md`, section `F8-09 Substitution table`.

**Mathematics:** One algebraic rule produces five input–output pairs, each paired in a glass neon table. The evaluator is a deterministic coefficient formula; no `eval`, Function or network dependencies are used. Negative quadratic substitutions use parentheses and correct order of operations.

## Interface and steps

- Board: mathematical rule above five neon input cards, a separate five-cell output row and a worked substitution evidence panel.
- Seven named teaching steps: Read rule → Choose input → Substitute → Apply operations → Fill first output → Complete table → Connect ordered pairs. Watch and Guided are controlled through the shared core timeline.
- Explore: place answer cards in any order, change an answer, use undo or reset, request a hint, then check all five outputs.
- Challenge: complete all five cells and check, with incorrect columns identified. The worked calculation hides its numerical result until the challenge is solved.
- Drag: NOVA.ui.svgDrag with five drop zones and red return zone; lift/glow/snap/spring-back controlled by F0. Keyboard click/Enter and Delete equivalent.
- Differentiation: five KS3 presets; quadratics and contextual linear modelling support GCSE transition.
- Accessibility: SVG has explanatory alt text, cards have button roles and keyboard handling, feedback uses aria-live, reduced-motion and print CSS are supplied.

## Misconceptions

- 3x is 3 times x, not 3 + x.
- Multiplication comes before addition/subtraction.
- A negative squared in brackets is positive.
- Put the output directly below the corresponding input.
- Add a fixed fee once only in the modelling context.
