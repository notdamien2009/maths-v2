# NOVA Native Helpers (virtual registry)

The current bank's approved Pip, Nova and Izaac mascot artwork is already embedded in the NOVA core/review runtimes. External historic folders such as `pip/pack80/`, `nova-cat/pack60/` and `teen/` are not present, and none are created as pretend sprite packs here.

`registry.json` identifies actual native selection APIs and broad standard pose intents that current reviewed source uses. It is descriptive metadata: **not** a replacement or new drawing library. To request an unavailable detailed pose, propose it separately for explicit approval rather than importing unknown artwork.
