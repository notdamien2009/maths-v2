## Objective: produce a sound lesson design, not paragraphs yet
1. Lock requested ID, year, title, strand, unit, **exact objective**, prior vocabulary/knowledge, neighbouring lessons and the one-sentence measurable learner outcome. Preserve the existing unit sequence and novel allocations. No random challenge selection.
2. Identify what the pupil does **not** know yet and sequence **3–5 meaningful concepts** from first principles. Four Bob beats per concept: `NOTICE / PREDICT`, `BUILD / REVEAL`, `EXPLAIN / EVIDENCE`, `GENERALISE / CARRY FORWARD`. Each beat needs a concrete source/visual/annotation action and a planned misconception response.
3. Choose **3–5 worked models** that genuinely differ in reasoning difficulty from Bob Board but are consistent with the same taught method. Do not repeat the same example text.
4. Design one distinctly purposeful **Explore investigation per concept**: identify the learner's action (highlight, rearrange, compare, revise, select evidence, edit sentence, etc.), response to wrong/correct and how they can retry. Do not disguise four identical quizzes as unique explorations.
5. Choose **one primary Challenge family** from the normalized map. Verify against actual objective and document any change with a rationale; output canonical family ID accepted by validator. If the family requires writing, define authentic student output and assessment rubric. If it is spelling, identify taught rule/word family, exceptions, meaning, usage and a stable `bankId` for site replay; an unrelated reading lesson must not award spelling mastery.
6. Plan original / appropriately licensed source passages, prompts, pictures and the **named connection** to the CGP reference's teaching approach. CGP = conceptual reference, not a source to copy. When unavailable, disclose the gap instead of inventing references.
7. Plan five Start diagnostics (prior learning only); 15 Practice credits Core/Secure/Stretch; 10 unseen Exit credits; at least one transfer task and differentiated misconception-specific feedback. Exit has no hints.
8. Mascots use original fixed-box positions only. Assign a teaching reason for each beat's cue (think/read/compare/check), with target phrase where relevant. Do not reintroduce lines or roaming movement.
