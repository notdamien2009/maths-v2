# RUN 4 — Strict English Teaching, Visual and Functional QA (Global)

## Purpose
Independently audit and repair a single English R3 HTML against actual Run1/Run2 sources, the approved English master, v2.0 contract, 256-lesson plan and **the three CGP books' instructional approach**, never by copying their passages. Do not rubber-stamp a pretty lesson. Report evidence for each check and label result REVIEW CANDIDATE unless GOLD evidence is complete.

## Mandatory acceptance gates
1. **Curriculum & teaching:** exact topic/year/goal; taught from first principles; 3–5 connected concepts, four substantive narrated beats each; explanations genuinely scaffold; no anticipatory learning that belongs in adjacent lessons; no content repeated without progress. Compare CGP for clarity, accuracy, worked modelling and assessment variety.
2. **Sources/content:** copyright/permissions and original text; check EVERY passage/question against key; numeric times, literary quotations, word rules and punctuation accurate; highlights and spoken text match exactly; no repeated answer giveaway, copied CGP question or lesson-inherited placeholder.
3. **Bob Board:** fixed **750px desktop**; no board scroll/cropping; no control movement across all beats; pause/play/skip-one-beat/previous/continuous navigation; no duplicate Learn; no invisible first slide; captions and Ryan narration (actual playback verified if possible). Do not claim audio verified if tool cannot listen.
4. **Explore:** one genuinely distinct concept-aligned investigation per concept; state and buttons usable on initial entry and after revisiting; inspect wrong/correct/retry, keyboard focus, explanations and task validity; no reused generic quiz pretending to be a new mechanic.
5. **Examples:** 3–5 separate, accurate worked models; original sources and progression; real distinct steps, controls and mascots; compare spoken reasoning with displayed source; no overflow/reflow.
6. **Challenge:** one primary family selected by objective and normalized allocation, justified override documented. Test EVERY required task: wrong/right/retry; original source; meaningful rubric/pending review for extended writing; spelling pattern, word meanings, unique `bankId` and no unintended passed spelling status in unrelated lesson. Unpiloted family is a **pilot gate**, not certified by a generic form.
7. **Assessments:** Start five slots exact; Practice 15 credits; Exit 10 credits fresh and independent; unique IDs/question forms, genuine correct answers, misconception-specific feedback; no Exit hints/live feedback; no fake exact-keyword creative-writing scoring; inspect the student-visible response and score states.
8. **Mascot/design:** all Pip/Nova/Izaac poses and selection lock; full-body Nova reading, no clipping of ears/paws/Izaac shoes; fixed teaching box, subtle intentional gestures; no pointing lines, moving character or oversized banner; royal blue everywhere. Test 1360px/1024px/768px and 390px, desktop priority but no mobile breakage.
9. **Engineering/accessibility:** no JS errors, excessive observer loops, unintended dependencies or blank panels, focus/keyboard/navigation, reduced motion, alt and contrast. Verify single HTML self-contained where expected. Test screen-reader semantics where feasible and note untested assistive technology explicitly.
10. **Persistence & deployment:** standalone reload where origin allows; real student save/hand-in only when tested on connected website. Don't claim live integration from localStorage smoke tests. No Git changes without explicit user approval.

## Repair discipline and deliverable
Fix genuine content/technical faults, regression-test affected pages AND one unrelated page. If template-level root cause repeats, issue a separate engine patch proposal/pilot rather than quietly changing the global master during lesson production.

Return `NOVA-ENGLISH-Y{year}-{NNN}-R4-REVIEW.html`, `Y{year}-{NNN}-R4-QA-EVIDENCE.json` and `Y{year}-{NNN}-R4-QA-REPORT.md` with per-gate PASS/FAIL/NOT TESTED, concrete screenshots/browser checks, question audit counts, real audio status, sign-off gaps and source hashes. **GOLD is forbidden** until every essential gate has evidence and user approves it; otherwise mark REVIEW CANDIDATE or BLOCKED. Do not use Run 4 to rewrite the lesson's learning objective or invent an unreviewed Challenge family.
