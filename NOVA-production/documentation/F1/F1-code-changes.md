# F1 source changes

All ten F1 HTML files were upgraded in place, preserving original CSS style blocks, embedded chalk fonts, SVG drawing functions, neon utility calls and mascot system. There are no separate F1 source/src companion files in this workspace. Original starting source is preserved in audit/f1-production-2026-10-16/originals.zip with SHA-256 identities.

Adapter/configuration changes: synchronized the canonical F0-tested lesson API, native Explore policies, speech restriction and embedded core fixes into F1; added nova-f1-contracts.js and nova-f1-motion.js. Every native step accepts an optional chips field without changing standard derived information. The registry records final hashes, configuration/step fields and scoped readiness. Existing source snapshots in generated lessons require regeneration.

Original drawing extensions are limited to F1-03 partial arc progress (original hops/rings) and F1-05 original hill ball position interpolation/concealment. Native F1-02/F1-05/F1-09/F1-11 accessible SVG descriptions no longer reveal withheld numerical answers. F1-01 neighbour labels and F1-09 division snapping honour offset axes. F1-06 keeps ordered boundaries and permits lesson-owned test values. F1-08 keeps configured small/large slider operands and correct exact-square-root bounds. F1-10 ordinary notation places the decimal point exactly. F1-11 negative truncation uses the correct open-lower/closed-upper interval and controls preserve sign. Family formatting retains up to nine decimal places; it is not an arbitrary exact-arithmetic engine.

Canonical core change: dragSnap snapping now anchors to its declared minimum instead of zero. Updated F1 inline copies carry this change; other families retain their embedded snapshots until their audits. The already released F0 source documents were not rewritten. F0-03/F0-04 passed a targeted regression of the updated approved template.

Template change: the existing native preview branch now recognises F1 from/to endpoint records, retaining the earlier F0 phase contract. Canonical original F0-12 factory and Challenge controller remain unchanged. All F1 compatible components mount this wrapper automatically through the approved lesson interface.

The patch, exact final source inventory, original backup, reproducible browser tests, question fixtures and screenshots are in the ZIP. Other families are not certified by this F1 audit.
