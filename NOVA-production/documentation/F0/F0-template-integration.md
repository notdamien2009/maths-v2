# F0 completion R2 — lesson production contract

Use the approved `00-master/NOVA-MATHS-LESSON-LAYOUT-TEMPLATE.html` and canonical F0 HTML paths from `integration/component-adapters.json`. Original apparatus and native configuration are authoritative. The capability manifest lists each source's actual parameter fields and native controls; do not pass invented generic numerical fields.

Watch, Guided and Bob records accept nativeIndex/data, native models/tables/scene arguments where declared, and per-record configuration. F0-03 regenerates named steps for configured jumps. Its optional `motion:{fromPhase,toPhase,durationMs}` uses the original tween and renderer. Previews show fromPhase; completion waits for real motion and narration. Pause/resume/cancel affect both. Duration is positive and at most 60000 ms; phase must fit the configured timeline. Start/size/endpoint are within ±1 billion, inputs up to four decimal places, jumps 0–100. Reduced motion displays the final state.

Explore bindings use native config/state plus `controls`, keyed by native accessible label (or explicit selector). Rules support hidden, disabled, selector, min, max, step, value and allowedValues. Groups and visual selectors can be hidden; sorting/matching/task groups can be restricted without replacing their original UI. Use the manifest's availableExploreControls catalogue. Policies survive native redraw and reset; numeric bounds and options constrain pupil interactions. Different components intentionally use different native schemas.

`views:[{record: nativeRecord}, ...]` supplies separate configured native scenes. `layout` is rows or columns; narrow widths stack. `exploreInstances:[{source,config,explore,title,instructions}, ...]` hosts one to four isolated original source documents. Omit source to reuse the current source. Each instance owns its configuration, controls, events and reset; it does not inherit another instance's mathematical preset. Both same-source and mixed F0-04/F0-16 instances were tested. Teardown disposes child instances.

Set `novaProductionData.narration.examples = true` to enable built-in Guided narration through existing Play/Pause/Resume/Reset. Browser speech requires a user gesture. External narration adapters remain supported. Future working/reasons are concealed until selected/reached. Captions remain available if speech fails; decimal digit-4 speech stays restricted.

Put `challengeGame` on the applicable `D.learn` concept. Put independent question records/keys in `novaProductionData.manifest.challenge`; six to eight questions were exercised. The original F0-12 wrapper mounts automatically; no later game integration pass is required. Practice lives default to zero; retryWrong is opt-in. Bounds: rounds 1–1000, lives 0–99, finite nonnegative scoring/hint values, three ascending star percentages from 0–100. The tested instructional contract remains the six/eight-question examples, not every possible game length.

Canonical modules in integration include the lesson API, contracts, Explore policy, speech policy, Guided narration, original F0-12 wrapper and lesson Challenge controller. Inline copies in all F0 documents and the template must remain synchronized. Embedded snapshots in previously generated lessons are not automatically rewritten. Rebuild lessons from this template/source and validate their actual questions before publication.

Native purpose limits remain explicit: F0-14's curve preset is its original quadratic; F0-15's display f text is not an arbitrary expression evaluator; F0-17 uses declared topics and 1–12 worksheet questions. Foundation demos retain their native role. Supported lesson editing does not imply arbitrary new mathematical operations.
