# F3 changes

All fifteen source documents now embed the canonical local core/API and Explore/speech policies once, with separate F3 contracts and runtime. The original renderers remain available. Optional data.lesson supplies exact native mathematical state, a static teaching phase, and timed native phases. Promise/cancel handling uses the template host clock. Static preview starts before future phases; reduced motion reaches the same endpoint. Actual Watch pause/resume/reset is honoured without changing the shared master template.

Native Explore bindings were added where missing; inputs remain original. Negative double-bracket editing now works in the F3 area-model entry. Deep factor trees fit above their collector and provide required factor cards such as 11 for 121. Square/cube partial builds no longer claim an incomplete number of units is the full power. Fractional-index diagrams use their actual root degree/numerator. Decimal grouping now counts groups with the correct group-unit divisor. Root Finder covers the full drag scale without gaps and includes the configured estimate on its axis.

Question results are concealed in relevant drawing readouts and accessible titles. Native sieve/table grid semantics and drag-source labels were repaired while preserving drawing order and working drag handles. Narrow-screen F0-12 question prompts use the available width. Original head CSS rules are unchanged; line endings were normalised. No replacement artwork or notation was introduced.

See source-changes.patch against originals.zip. F0/F1/F2 source, shared canonical core/API and the approved master template were not changed for F3. Only F3 registry entries were updated after verification. Historical approval/TBD gates remain superseded by the existing 14 October release.
