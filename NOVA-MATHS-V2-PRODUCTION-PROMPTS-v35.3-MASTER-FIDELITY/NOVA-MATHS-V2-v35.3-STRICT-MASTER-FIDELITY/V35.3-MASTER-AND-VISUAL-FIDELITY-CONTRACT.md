## Rule 4 — Bob Board must TEACH the maths fully

Bob Board is one uninterrupted teaching presentation across all five stages of the same lesson objective. Target twenty genuinely different BEATS: per stage (1) NOTICE/PREDICT—activate prior knowledge and pose an observable question, (2) BUILD/REVEAL—animate the native apparatus and change the displayed maths in interpretable steps, (3) EXPLAIN/EVIDENCE—explain *why* it is correct using digit worth/quantity/relationship/invariant and correct a likely misconception, (4) GENERALISE—state the transferable rule, when it applies, why, and use a new check. These are not four identical images with different headings.

For EACH beat require: displayed equation/values/units, native source/preset, start→intermediate→end drawing, highlights and deliberate reveal timing, spoken Bob explanation in pupil-accessible language, synchronised visible captions, purpose, likely misconception and responsive evidence, exact completion signal, reset/skip cancellation. Bob must teach from zero with clear reasoning; never “here is the answer” without working, repeated filler scripts, unexplained jargon or one short sentence presented as a deep-dive. Do not add new buttons or remove Bob portrait/key words card. Keyword pills individually display concept-correct definitions on click, click again closes, keyboard toggles; opening a definition must not interrupt presentation. Pressing existing Play starts native steps+speech; forward skip while autoplay remains playing, Stop truly stops, restart begins at chosen place, concept handoff does not end playback. Sound-off fallback keeps full captions on screen long enough to read them.

Watch uses original animated native component and existing Play for auto narration; Explore uses real independent manipulation plus clear how-to directions; Challenge uses original F0-12 game; Examples Guided has fully explained worked steps and TTS via existing Play. Examples cover the teaching and should not simply repeat a final answer. Tests must inspect actual native drawing, not only count records.
