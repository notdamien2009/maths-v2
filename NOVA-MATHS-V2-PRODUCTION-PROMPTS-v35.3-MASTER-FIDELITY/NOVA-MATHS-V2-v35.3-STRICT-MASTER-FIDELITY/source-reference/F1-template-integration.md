# F1 lesson integration

Use `00-master/NOVA-MATHS-LESSON-LAYOUT-TEMPLATE.html`, canonical F1 HTML from `integration/component-adapters.json`, and the original F0-12 controller. The source ID mapping embeds the original apparatus. Existing generated lesson HTML must be rebuilt because it contains source snapshots.

Lesson records select `source`, `nativeIndex`, `data` and/or `scene:{function,arguments}`. Use the manifest’s exact drawing signatures. Arguments merge with the selected native drawing’s defaults. Supply full mathematical state and explicit visibility flags when changing context: inherited `o.n:0`, `o.pointer:false` or `o.seg:false` otherwise deliberately remain in effect. `data.st` replaces its whole native step state; supply the complete schema. Never change a native step name as a display title. Use the lesson title/teaching fields instead.

All native steps accept optional `chips`. `chips:[]` removes old demonstration working when a lesson supplies its own question. `null` preserves default derived information in components such as the inequality line. Six distinct questions per component are supplied in F1-configuration-examples.json with independent answers and unanswered states.

For custom Watch/Guided/Bob motion use `motion:{from:{data,scene},to:{data,scene},durationMs}` on a record. Endpoint records accept only data/scene. The duration is positive and at most 60000 ms. Motion uses original native renderers and geometry. Numeric positions and numeric labels interpolate; count, level, exponent, accuracy and other discrete fields switch at the endpoint. Textual reveals switch at the endpoint. Author teaching captions for the actual native states, rather than expecting an expression parser. F1-03 uses `o.progress` from zero through jump count to grow partial original arcs; F1-05 uses `o.rollProgress` from 0 to 1. F1-11 motion reveals a fixed measured interval; changed measurement/accuracy belongs in a separate record. Hosted previews show the starting state; reduced-motion playback shows the final state. The host clock coordinates pause/resume and cancellation.

Put per-concept native settings in `novaProductionData.componentConfigs[concept.id]`. Put focused Explore bindings in `novaProductionData.exploreBindings[conceptIndex]`, for example `variables:{st:{value:{min:0,max:1,labelStep:0.1,step:0.01,value:0.37}}}` for F1-01. Hydrated Explore state preserves other native fields. For F1-06, `t:{value:0.75}` selects the exact independent test x; `showI:{value:true}` shows integer solutions.

The binding’s `controls` map is keyed by native accessible labels from the manifest. Rules accept hidden, disabled, min, max, step, value, allowedValues and selector. Example: `controls:{Preset:{allowedValues:['tenths']},Value:{min:0.2,max:0.8,step:0.01},Stepper:{hidden:true}}`. Set initial mathematical state to match the chosen preset/ranges. Policies constrain native controls and survive redraw/reset. Hide a visual region only when doing so preserves the underlying mathematical relation. These F1 components do not have place-value columns; column selection is not applicable here.

Use `views:[{record:firstRecord},{record:secondRecord}]` with `layout:'rows'` or `'columns'` for two original scenes. SVG references are scoped. For independent live controls use `exploreInstances:[{source,config,explore,title,instructions},...]`, one to four original source frames. Omit source to reuse the current component. Each frame owns state, input and reset. Rows/columns and separate live values/keyboard/reset were checked for every F1 source. Pointer input and mobile stacking were additionally tested on two F1-01 charts, and mixed F1-01/F1-09 engine/configuration state was checked.

Challenge uses the original F0-12 automatically. Put game options on the `D.learn` concept’s `challengeGame`, and independent question states/keys in `P.manifest.challenge`. Use six to eight questions. Retain unanswered flags: F1-01 comparison `o.unanswered:true`; F1-02 unknown marker `o.label:'?'`; F1-03 `o.end:false` plus explicit jump visibility; F1-05 `o.conceal:true,arrow:false`; F1-08 `o.est:false`; F1-09 `o.conceal:true,pointer:true`; F1-10 appropriate hidden-placement mode; F1-11 `o.seg:false`. Scale marks or geometric locations may naturally support a pupil’s calculation; the numeric result itself must stay concealed. Set lesson chips explicitly. Question records must include exact units, answerType, privateAnswer, hint and feedback. The tested practice/lives/retry/scoring/celebration contract is unchanged from F0.

Set `P.narration.examples=true` for built-in Guided speech using existing controls. Bob uses the existing TTS control. Real speech may require a user gesture and falls back to captions/read timing on failure. Decimal numerals containing digit 4 remain caption-only until pronunciation is verified. Spoken pronunciation has not been certified for every voice.

Native limits are listed per component in the manifest. F1-08 supports positive estimates; F1-10 supports positive standard form; F1-11 rejects zero truncation and unsupported calculations. Negative halfway rounding follows the original greater-landmark convention. New lesson questions still require rendered mathematics/answer review.
