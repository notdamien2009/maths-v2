# F2 code changes

All fifteen documents now embed the canonical local core and lesson API once, plus shared Explore/speech policies and the separate F2 contracts/runtime. Each original native step accepts optional data.lesson. Native constructors, SVG apparatus, palette, chalk fonts, controls and mascot remain authoritative. Original head CSS blocks are unchanged; a small F2 runtime media rule stacks the question and answer on narrow screens.

The F2 runtime invokes original operations and tracks their completion/cancellation. Native animations stay on the approved template's host clock. Static lesson previews suppress future actions. Native SVG semantics are repaired without replacing the drawing. Config validators reject unsupported lesson numbers, counts, operations and actions before rendering.

Place-value/chart/counter/abacus focus now uses original place identities. All calculated lesson working is built from lesson operands and state. Repairs cover zero multiplication, division quotient precision/bounds, zero expansion, standard-form comparison labels, correct dynamic cube-root/fractional-index notation, bracket-aware BIDMAS, hidden question results in accessible titles, exact-set classification, independent reset bindings, read-only keyboard controls, and stable touch capture when SVG redraws.

See source-changes.patch for exact changes against originals.zip. F0/F1 source and the approved master template were not modified for F2. The shared registry was updated only for the F2 entries after verification. Existing production approval and NOVA stacked fraction decisions were preserved.
